# College Demonstration Checklist

- [ ] Start MongoDB and run `npm run dev`.
- [ ] Open `http://localhost:5173`.
- [ ] Register a fresh account.
- [ ] Create a sample project and set its hourly rate.
- [ ] Start a timer and allow it to run for 15–30 seconds.
- [ ] Stop the timer and show the completed session.
- [ ] Open the Timesheet page and explain duration and estimated earnings.
- [ ] Open Reports and explain the charts.
- [ ] Open Settings and update the profile.
- [ ] Be prepared to explain JWT, bcrypt, REST APIs, MongoDB schemas and timer calculation.
